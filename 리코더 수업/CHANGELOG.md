# 소프라노 리코더 연주하기 — 수정 기록

## 2026-08-30

- `index.html`(수업 자료 시작 페이지)과 `악보 다운로드.html` 신설 — 종묘제례악/대취타 폴더의 index.html 구조(큰 버튼 1개 + 작은 버튼 2개 + 푸터)를 참고해, 리코더 앱 고유의 색상·폰트(Gowun 계열, 코랄·플럼·골드)로 재구성
  - index.html: "수업 시작하기"(메인 앱) + "악보 다운로드" + "운지법 프로그램"(exe) 3개 링크
  - 악보 다운로드.html: 세 곡(생각해줘요·라 캄파넬라·녹턴)의 계이름 악보 이미지를 곡별 카드로 정리, 각각 다운로드 버튼(`download` 속성) 제공
- 어려운 음(라 캄파넬라 높은도·높은도#·높은레·높은미·솔#·시b·파, 생각해줘요 낮은도#·높은도#·높은레·높은미·라#·파#) 개별 운지 이미지를 운지표 슬라이드에 추가
- 악보 이미지 검은 테두리 제거
- "학습 순서" 슬라이드 삭제
- 운지표 통합 이미지 삭제 → 어려운 음 낱개 이미지를 한 화면 그리드로 배치, 클릭 시 라이트박스로 확대
- 원악보 슬라이드 삭제 (계이름 악보만 유지)
- 악보 잘림 버그 수정 — 원인은 CSS가 아니라 HTML에 박혀 있던 옛 세션의 크롭된 이미지 데이터였음. 디스크의 현재 파일로 재삽입
- 자세·주의사항 슬라이드에 "리코더 연주자세.png" 사진 추가 (왼쪽 사진 + 오른쪽 텍스트 카드 2개 세로 배치)
- 본문 글씨 크기 확대, 한 줄로 줄바꿈 없이 표시
- "주법 연습 악보" 슬라이드 신설 (텅잉/이음줄 다음, 논레가토·레가토·포르타토·스타카토 악보)
- 운지표 제목에서 "· 어려운 음" 문구 제거 (단순히 "운지표"로)
- 운지표 각 카드: 계이름 라벨을 이미지 위로 이동, 크고 굵게, 곡별 색상(생각해줘요=green, 라캄파넬라=plum) 네모 배지로 표시
- 텅잉 주법 / 이음줄(레가토) 연주 슬라이드의 유튜브 임베드가 로컬 file:// 환경에서 오류 153(재생 불가)을 일으켜, 썸네일 이미지 + 재생 버튼 형태의 링크 카드로 교체 (클릭 시 유튜브로 새 탭 이동)
- 영상 영역 축소, 텍스트 카드 확대 + 본문 글씨 크게
- 모든 슬라이드의 강조(`<b>`) 텍스트에 곡/섹션별 색상 적용 (accent-a=green, accent-b=plum, accent-n=gold)
- 라 캄파넬라 계이름 악보의 BPM 재생 목록을 레코드판이 도는 커스텀 플레이어로 교체 — "빠르기 1~8" 단계 표시 + BPM 소표기, 재생 중 vinyl 회전 애니메이션, 진행률 바
- 슬라이드 삭제/추가 때마다 트랙 폭·슬라이드 폭 CSS 값(TOTAL 개수 기준)을 함께 갱신 — 현재 총 9슬라이드
- 운지표 카드를 클릭하면 해당 음의 소프라노 리코더 음높이를 Web Audio API로 직접 합성해 재생 (실제 음원 파일을 구할 필요 없이 정확한 주파수로 즉석 생성 — 표준 리코더 운지 음이름·옥타브 대응표 기준)
- 바른 자세와 주의사항: "연주 자세" 카드 색상을 "주의사항"과 동일한 보라색(plum) 계열로 통일
- 텅잉 주법 / 이음줄(레가토) 연주: 본문 글씨를 대폭 확대(뒷자리에서도 보이도록), 유튜브 카드 비중 축소
- 운지표 라이트박스(클릭 시 확대 팝업) 완전 삭제 — 클릭하면 소리만 재생되도록 단순화, 대신 클릭 시 카드에 짧은 하이라이트 효과
- 라 캄파넬라 빠르기 1~8 레코드판 플레이어에 실제 재생 로직이 빠져 있던 버그 수정 (클릭해도 소리가 안 나던 문제 — 디자인만 만들고 JS 이벤트 연결을 누락했었음)
- 상단 내비게이션의 "계이름·듣기" / "계이름" 라벨을 "연주하기"로 통일
- 텅잉 주법 / 이음줄(레가토) 연주: 본문을 카드 안에서 위아래 여백 없이 고르게 채우도록 배치(justify-content:space-evenly), 글씨 추가 확대, 영상 카드 비중을 더 축소
- 운지표 카드 클릭 시 선택 표시를 지속형으로 변경 — 다른 카드를 누르기 전까지 금색 테두리·그림자로 계속 표시되어 어떤 음을 눌렀는지 알 수 있음
- 라 캄파넬라 빠르기 목록: BPM 숫자 표기 제거, 레코드판 크기 확대(42px→56px), 클릭 시 Web Audio GainNode로 음량을 2.5배 증폭

- 텅잉 주법 슬라이드 내용 오류 수정 — "스타카토·짧은 음표가 많은 부분에 주로 사용해요"는 부정확한 설명(텅잉은 이음줄이 아니면 사실상 모든 음의 기본 주법)이라 웹 검색으로 확인 후 "이음줄(슬러)로 묶이지 않은 모든 음에 기본으로 사용하고, 스타카토·짧은 음표에서는 더 짧고 또렷하게 끊어줘요"로 정정

- 운지표 클릭 표시를 야광 네온 그린(#39FF88) 두꺼운 테두리 + 글로우 + 팝업(살짝 커졌다 자리잡는) 애니메이션으로 강화 — 멀리서도 어떤 카드를 클릭했는지 뚜렷하게 보이도록 개선
- 라 캄파넬라 빠르기별 반주 음량을 대폭 증폭(게인 2.5배→6배) + 다이내믹 컴프레서 추가로 소리가 찢어지지 않으면서 훨씬 크게 들리도록 조정

- 두 곡의 "곡 소개" 슬라이드 신설 (각 곡의 연주하기 슬라이드 앞) — 웹 검색으로 사실 확인 후 작성
  - 생각해줘요: 원제 "Think of Me", 앤드루 로이드 웨버 작곡, 뮤지컬 <오페라의 유령>(1986) 수록곡, 크리스틴이 부르는 노래
  - 라 캄파넬라: "작은 종"이라는 뜻, 리스트가 파가니니 바이올린 협주곡 2번 3악장(핸드벨 모방 부분)을 편곡한 피아노 연습곡
  - 총 슬라이드 9 → 11개로 증가, 관련 CSS/JS(TOTAL, 트랙 폭, 내비게이션 pill) 동기화
- 슬라이드를 이동하거나(화살표·점·상단 메뉴 클릭) 운지표 음을 클릭하면 재생 중이던 반주/음원이 자동으로 정지되도록 수정

- 곡 소개 슬라이드에 이미지 추가, 본문이 카드 안에서 화면을 가득 채우도록 레이아웃 변경(justify-content:space-evenly)
  - 생각해줘요: 〈오페라의 유령〉 가면무도회 장면 삽화(André Castaigne, 1911년 미국판 삽화 — 퍼블릭 도메인)
  - 라 캄파넬라: 프란츠 리스트 초상화(Henri Lehmann, 1839), 니콜로 파가니니 초상화(Ingres, 1819) — 모두 위키미디어 커먼즈 퍼블릭 도메인
- 이음줄(레가토) 연주 슬라이드의 유튜브 영상 교체 — 기존 영상이 실제로는 붙임줄/이음줄 "이해"와 높은음 운지 위주라 내용이 맞지 않아, 지학사 티솔루션 공식 채널의 "초등 음악 리코더 연주법" 영상으로 교체

- 이음줄(레가토) 연주 영상을 사용자 지정 링크로 교체 — "[천재교육 티셀파] 리코더 아티큘레이션2(레가토)" (레가토 주법을 정확히 다루는 영상으로 확인 후 적용)

- 텅잉 주법 영상을 사용자 지정 링크로 교체 — "[천재교육 티셀파] 리코더 아티큘레이션3(논 레가토)" (같은 시리즈의 이음줄 영상과 짝을 이룸)

- 라 캄파넬라 빠르기별 반주(camp100~170) 8개 파일을 재생 길이로 검증 — 앞부분 약 3.9초 고정 인트로를 제외하면 BPM에 정확히 반비례(같은 연주의 속도 변형본)함을 확인
  - camp130(중간 속도) 음원 1개만 남기고 나머지 7개 삭제, 재생 시 `audio.playbackRate = 목표BPM/130`으로 속도 조절 + `preservesPitch`로 음정 유지
  - 파일 용량 11.4MB → 7.0MB로 감소 (오디오 페이로드 3.6MB → 0.6MB)
  - 인트로 약 3.9초 구간만 속도별로 실제 렌더링본과 미세하게 다를 수 있음(음악 본편은 동일)
  - 더 이상 쓰이지 않는 원본 wav 7개(100·110·120·140·150·160·170) 폴더에서 삭제, 130.wav만 원본 소스로 보관

- **녹턴(Nocturne) 세 번째 곡으로 신규 추가** — 앞선 두 곡과 동일한 구조로 구성 (총 11 → 14슬라이드)
  - 곡 소개: "야상곡"이라는 뜻, 존 필드가 창시하고 쇼팽이 완성한 장르라는 설명 + 프레데리크 쇼팽 초상화(Delacroix, 1838년作 — 퍼블릭 도메인)
  - 연주하기: 계이름 악보 + 반주 음원(wav 6.35MB → mp3 1.1MB로 압축)
  - 운지표: 어려운 음 7개(파#·낮은레#·높은도·높은도#·높은레·높은미·높은솔) 그리드, 클릭 시 리코더 음 재생 — 낮은레#(622.25Hz)·높은솔(1567.98Hz) 주파수를 새로 추가
  - 표지 슬라이드에 "3곡 · 녹턴" 칩 추가, 상단 내비게이션에 녹턴 그룹(곡 소개/연주하기/운지표) 추가

- 녹턴 소개 문구 보강: 쇼팽의 녹턴은 총 21곡이라는 정보, 이번 편곡이 그중 가장 유명한 <b>녹턴 2번(Op.9 No.2)</b>이라는 점, 원곡 내림마장조(E♭)를 리코더 연주에 맞게 <b>사장조(G)로 조옮김</b>했다는 점을 명시 (사용자 확인 후 반영)
- 녹턴 반주 재생 시에도 라 캄파넬라와 동일하게 게인 6배 증폭 + 컴프레서 적용, 생각해줘요/녹턴 반주가 서로 동시 재생되지 않도록 상호 정지 처리
- 세 곡의 "연주하기" 슬라이드 제목을 전부 "연주하기"로 통일 (생각해줘요·라캄파넬라는 "계이름 악보"로 남아있던 것 수정)
- 녹턴 운지표의 계이름 라벨에도 다른 두 곡처럼 색상 배지 적용 (골드 계열)

## 참고
- 라 캄파넬라 반주 음원(camp100~170)은 원본 wav(개당 8~13MB, 총 85MB)가 아니라 MP3로 변환해 삽입되어 있음 (개당 약 600KB). 파일 용량을 줄이기 위한 의도적 선택. wav 원본 그대로 넣으면 파일이 100MB 이상으로 불어남.
